# Picture-and-Video-Organizer
Python script to sort pictures and videos by creation/taken date along with renaming the file to the date.
The script will copy from the source folder and subfolders, and place in the destination folder; The source folder will be untouched.


1. Download and install Python (https://www.python.org/)
2. In terminal, run: "pip install Pillow exifread hachoir"
3. Run the python script.
   a. Select where to source the files from, and where to place them (Be in seprate directories to prevent infinite loop)
   b. Click "Start Organizing"
